# Food Aggregator

Бесплатный Android-прототип агрегатора доставки еды для Мурманска и Североморска.

На текущем этапе это офлайн-оболочка с выбором города и интерфейсом каталога. Реальных ресторанов и заказов пока нет.

## APK
Откройте вкладку Actions → Build Android APK → последний успешный запуск → Artifacts → food-aggregator-debug-apk. Распакуйте ZIP и установите app-debug.apk на Android.
